# GramFi — продуктовый ролик v2 (61 с, 1920×1080, 60 fps)

**Идея:** «Крипта говорит в Telegram — GramFi превращает разговор в сигнал, а сигнал — в сделку».
Слоган: *AI-powered InfoFi platform built for the Telegram ecosystem.*
Веб-половина — *увидеть* (9 инструментов Insight), мобильная — *действовать* в Telegram-боте (5 функций).

**Стиль:** светлые UI-карточки с мягкими тенями в 3D-перспективе на **цветных фонах глав** (лайм, лаванда,
ink, небесный, мята, коралл). Смена главы — круговая векторная «волна» цвета из точки клика. За интерфейсом —
векторные мотивы главы (рамки treemap, дуги, орбиты, волны, созвездия, лучи, шестерёнки, свечи, кольца),
дорисовываются линией и дают параллакс. Крупный курсор: наведение → клик → смена состояния → результат.
Логотип — векторная копия фирменного знака (жёлтый сквиркл, стрелка с прорезью и точкой).

**Музыка:** присланный трек (140 BPM), вырезан по фразам: ролик 0–56.57 с ← трек 51.47–108.04 с;
финал ← трек с 125.2 с (родное затухание). Дроп трека (84.04 с) = 32.57 с ролика = приземление телефона;
полёт телефона идёт ровно в брейке трека. Все смены глав стоят на долях (B = 0.4286 с).

## Файлы

- `index.html`, `scene.js` — сцена; `renderAt(t)` — чистая функция времени.
- `render.js` — рендер кадров на 120 fps; `build.sh` — сборка: пары субкадров → 60 fps (motion blur), звук → −14 LUFS, MP4.
- `audio.py` — нарезка трека `assets/music.mp3` по сетке + синтез UI-звуков по `events.json`.
- `preview.js` — отдельные кадры: `node preview.js out_dir 4.6 13.2 32.6`.
