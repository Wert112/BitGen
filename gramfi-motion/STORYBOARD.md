# GramFi — продуктовый ролик v3 (66.9 с, 1920×1080, 60 fps)

## Что зритель должен вынести

1. GramFi помогает разобраться в криптообсуждениях Telegram.
2. Он показывает, *что* обсуждают, *где* и *кто* двигает разговор — вплоть до конкретного поста.
3. Дальше можно действовать в Telegram: Polymarket-бот (ставки, копитрейдинг, автотрейдинг, перпы, алерты).

**Сквозной объект — BTC и один рынок.** Плитка BTC растёт в treemap → BTC в топе Южной Кореи → канал
Trade Nobody на карте → его пост «$BTC 86k… Polymarket 43% YES на закрытие выше $90k» → вкладка Polymarket,
тот же рынок → бот в Telegram → ставка на этот рынок, затем алерт на этот же рынок.

**Иерархия сцен:** опорные (вопрос → действие → результат → пауза на чтение): Most Popular Coin, Channel Map →
Feeds/Telescope, ставка в боте. Короткие сцены возможностей — одна подпись, без лишних действий.

**Стиль:** тёмная тема сайта, тёмные карточки, лайм-акцент; бот — ночная тема Telegram. Цвет закреплён за
смысловыми группами (фоновое свечение): внимание — лайм, источники — фиолетовый, действие в Telegram — голубой,
финал — лайм. Полные цветовые переходы только между крупными частями; внутри веба страницы меняются в той же рамке.
Фоновые мотивы — только по смыслу (рамки treemap, сеть каналов, сообщения, свечи) и приглушаются при изменении данных.
Анимация данных без пружин; отскок — только у декоративного (приземление телефона, колокольчик, корона).
На вебе — курсор, на телефоне — индикатор касания.

**Музыка:** присланный трек, 140 BPM. Ролик 0–60.0 с ← трек 51.47–111.47 с; финал ← трек с 125.2 с (родное
затухание). Обе склейки — на границах 8-тактовых фраз. Дроп трека = 32.57 с = приземление телефона; полёт — в брейке.

## Файлы

- `index.html`, `scene.js` — сцена; `renderAt(t)` — чистая функция времени.
- `render.js` — кадры 120 fps; `build.sh` — пары субкадров → 60 fps (motion blur), звук → −14 LUFS, MP4.
- `audio.py` — нарезка `assets/music.mp3` по фразам + UI-звуки по `events.json`.
- `preview.js` — отдельные кадры: `node preview.js out_dir 8.0 26.4 37.6`.
- `gramfi_motion_v2.mp4` — предыдущая версия (светлая).
